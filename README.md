# ExamNews - GitHub Pages Starter

A free static portal for:
- Government Jobs
- Competitive Exams
- Admit Cards
- Results
- Syllabus
- Previous Papers
- Scholarships
- Education News

## Publish on GitHub Pages
1. Create a new public GitHub repository.
2. Upload all files and folders from this project.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**.
6. Save and open the GitHub Pages URL.

## Important customization
- Replace `ExamNews` with your final brand name.
- Replace placeholder email.
- Update `robots.txt` and `sitemap.xml` with your real GitHub Pages URL.
- Replace sample posts with verified, original articles.
- Always link to official notifications.
- Do not claim to be an official government website.

## Add a new post
1. Copy one file inside `posts/`.
2. Rename it, for example `ssc-cgl-2027.html`.
3. Replace title and content.
4. Add a card/link for it on `index.html`.

## Monetization readiness
Before applying to an ad network:
- Publish substantial original content.
- Keep About, Contact, Privacy Policy and Disclaimer updated.
- Avoid copied job notifications or thin pages.
- Use official sources and write your own summaries.
